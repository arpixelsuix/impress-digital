# Impress Digital

A responsive digital agency website built with HTML, CSS and JavaScript.

**Live demo:** https://arpixelsuix.github.io/impress-digital/

## Features
- Responsive layout with hamburger menu
- Scroll animations, animated stats counter, scroll-spy navigation
- Portfolio hover effects and blog cards
- Contact form with validation (Web3Forms)

## Built With
HTML5, CSS3 (Grid, Flexbox), Vanilla JavaScript
